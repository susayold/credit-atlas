# Excel assets

The blank portfolio and affordability input workbooks are public templates. Some builders in this folder and `scripts/` use the host-provided `@oai/artifact-tool` package, which is not distributed in this repository. The dependency is intentionally not copied from the local runtime. The workbooks themselves remain available for direct use in Excel, and the Python app adapters are covered by the public test suite.

The D02 data-reference workbook includes publisher-attributed public tables. To refresh its FHFA NMDB state panel, first rebuild `CreditAtlas-D02-Data-Reference.xlsx` with the host `build_d02_data_reference.mjs` workflow, then run `python scripts/add_nmdb_state_to_reference_workbook.py`. The second step appends the 79,968-row state table and definitions sheet while preserving blank/suppressed values and the other workbook tables.

The public [Toyota](templates/CreditAtlas-Toyota-Recovery-Exception-Ledger.xlsx) and [Nissan](templates/CreditAtlas-Nissan-Exception-Ledger.xlsx) exception workbooks provide formula-driven summaries, filterable period ledgers, and method/source notes. Both contain source-linked monthly aggregates only; unresolved residuals remain visible and are not interpreted as LGD or model results.

The [structured ABS surveillance workbook](templates/CreditAtlas-ABS-Surveillance-Exceptions.xlsx) combines Toyota 2022-B, Toyota 2024-B and Nissan 2024-B in a 103-period, source-linked exception ledger. Summary formulas calculate recovery ties and residuals within each deal contract only; the comparators differ by trust, so the workbook intentionally has no pooled recovery-dollar total or pooled tie rate. It includes data-contract definitions and the open analyst finding; it contains public filing aggregates, not loan-level records.

The [Bondora N14 label-support workbook](templates/CreditAtlas-Bondora-N14-Label-Support.xlsx) contains aggregate counts by origination year, country and country × year, plus a diagnostic 12-month maturity proxy. Country-year cells under 50 are suppressed. It contains no loan IDs or loan-level rows and does not turn unresolved NULL labels into negatives; the publisher cutoff and label construction remain open research questions.

The [HMDA Browser release audit workbook](templates/CreditAtlas-HMDA-Browser-Release-Audit-2018-2025.xlsx) compares official Browser-selected action-count aggregates for 2018–2025 with the app's stored One-Year archives, adds release-state deltas for 2019–2022, and records API/source lineage, KPI definitions, privacy and rights limits. It contains only aggregate counts, not raw LAR rows. The builder is `build_hmda_browser_release_audit.mjs`; the public data and native Excel QA receipts are under `docs/data/`.
